# 《烬境旅团》研发文档中心

## 文档定位

本目录是项目需求与研发决策的唯一事实来源（Single Source of Truth）。实现与文档冲突时，先确认需求并更新文档，再修改代码。所有文档使用版本号和状态标识：

- `草案`：允许讨论，不可直接作为验收依据。
- `评审中`：核心方案已形成，仍可能调整。
- `已批准`：可进入实现，变更必须记录原因。
- `已实现`：代码和验证结果均已落地。

## 决策优先级

1. 已批准的专项文档优先于概述性 GDD。
2. PRD 定义“做什么”，TDD 定义“如何实现”，数值文档定义“具体参数”。
3. 未定义的功能不得由实现者自行扩展；记录为 `TBD` 并发起评审。
4. MVP 不包含排行榜、公会、世界 Boss、宠物、赛季等后续版本内容。

## 已确认技术决策

- `DECISION:` 游戏中文名为《烬境旅团》，英文工作名为 `Ashrealm Brigade`，内部代号为 `Ashrealm`。
- `DECISION:` 客户端采用 Cocos Creator 3.8.8 + TypeScript，创建 2D 项目。
- `DECISION:` 微信小游戏为 MVP 首发平台，Web 构建用于日常快速调试。
- `DECISION:` 微信基础库最低兼容版本为 2.12.0；开发调试使用微信开发者工具提供的当前稳定基础库。
- `DECISION:` 游戏规则与平台能力分层，业务代码不得直接调用 `wx.*`。
- `DECISION:` 所有开发者、CI 和构建环境统一使用 Cocos Creator 3.8.8；未经技术评审不得升级编辑器版本。

## 变更流程

需求变更应同时更新受影响文档，并在 PR 中列出：变更原因、影响模块、存档兼容性、配置迁移、测试范围。关键决策使用 `DECISION:` 标记，未决项使用 `TBD:` 标记；批准后删除 `TBD` 并记录结论。
